To create a RepositoryMirror resource, you need to:

1. Create a Secret with Quay credentials:
   kubectl create secret generic quay-credentials \
     --from-literal=host=quay.example.com \
     --from-literal=token=YOUR_TOKEN

2. Apply a RepositoryMirror custom resource:
   apiVersion: quay.ayoy.se/v1alpha1
   kind: RepositoryMirror
   metadata:
     name: my-mirror
   spec:
     name: myorg/myrepo
     connSecretRef:
       name: quay-credentials
     externalReference: registry.example.com/namespace/repository
